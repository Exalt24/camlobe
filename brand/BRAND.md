*The name, mark and colours of Camlobe, a lab pipeline that turns messy supplier parts feeds into one catalog.*

## Name

Camlobe. A cam lobe is the part of a camshaft that does the lifting, and the project lifts one clean catalog out of several supplier feeds. Seven letters, one word, easy to say and spell.

Backups, in order: Lugnut, Cotterpin.

## Evidence

Checked 2026-10-25 with `brand_name_check.py Pushrod Tappet Lugnut Cotterpin Camlobe`.

| Check | Camlobe |
|---|---|
| .com, .io, .app, .dev | no registration found in any of the four |
| GitHub user or organisation | none |
| npm, PyPI, crates.io | no package in any |
| Apple App Store | no app with this name in the top results |

Pushrod, Tappet, Lugnut and Cotterpin each had at least one taken registry or domain, which is why Camlobe was chosen.

The manual trademark search (USPTO, WIPO, IPOPHL, TMview, classes 9, 35 and 42) has NOT been run. It is owed before the name is used for anything sold. "Camlobe" is the working name, not a claim of ownership.

## Fonts

None of its own. The social preview uses the icon kit's default sans serif. No wordmark font is shipped, so there is no font licence to record.

## Mark

A cam lobe in profile with its shaft hole: a teardrop with a round hole, drawn as one path on a 64 by 64 grid in `master.svg`, white on the teal square. One idea, one colour, no text inside it. The icon set in `icons/` was exported from that one file with `brand_icon_kit.cjs` and passed its `--check` (sizes, alpha, limits).

Minimum size: 16 px (the favicon). A tester should know that the shape reads as a drop of water at that size; the shaft hole is what makes it a cam, so on a plain background keep the hole.

Not independently reviewed. A public mark gets two outside reviewers (research-waves 5b) before it is called finished.
